First-class functions & higher-order functions - Senior Assessment

Topic slug: js-core/first-class-higher-order-functions | Variant seed: 61

Q1. What does it mean for functions to be "first-class citizens" in JavaScript?
Expected answer signal

Functions can be assigned to variables, passed as arguments, returned from other functions, and stored in data structures.

Q2. Define a higher-order function and give two examples from the JavaScript standard library.
Expected answer signal

A function that takes one or more functions as arguments, returns a function, or both. Examples: Array.prototype.map, Array.prototype.filter, setTimeout.

Q3. Why are higher-order functions important in functional programming?
Expected answer signal

They enable abstraction, code reuse, and composition by allowing functions to operate on other functions.

Q4. Provide a code sample that demonstrates a higher-order function returning a function.
Expected answer signal 

{`function makeMultiplier(x) {
  return function(y) { return x * y; };
}
const double = makeMultiplier(2);
console.log(double(5)); // 10
`}

Q5. How do first-class and higher-order functions enable patterns like middleware or event handling?
Expected answer signal

They allow functions to be passed, composed, or wrapped, enabling flexible APIs like middleware chains or event listeners.
