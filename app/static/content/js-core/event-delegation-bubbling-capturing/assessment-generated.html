Event Delegation, Bubbling, Capturing - Senior Assessment

Q1. Explain the difference between event bubbling and event capturing in the DOM event flow.
Expected answer signal

Bubbling: event flows from target up to root; Capturing: event flows from root down to target. Handlers can be attached in either phase.

Q2. What is event delegation and why is it useful?
Expected answer signal

Attaching a single handler to a parent to manage events from multiple children, leveraging bubbling. Useful for dynamic lists and performance.

Q3. How do you attach an event handler for the capturing phase?
Expected answer signal

Pass true as the third argument to addEventListener: element.addEventListener('click', handler, true).

Q4. Provide a code sample that demonstrates event delegation for a list of items.
Expected answer signal 

{`document.getElementById('list').addEventListener('click', function(e) {
  if (e.target.matches('li')) {
    console.log('List item clicked:', e.target.textContent);
  }
});`}

Q5. What are potential pitfalls of event delegation?
Expected answer signal

Event delegation may not work for events that don't bubble (e.g., focus, blur), and event.target may not always be the intended child element.
