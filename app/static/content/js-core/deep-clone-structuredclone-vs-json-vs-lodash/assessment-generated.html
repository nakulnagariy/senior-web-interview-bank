Q1. What is deep cloning and why is it important in JavaScript applications?
Expected answer signal

Deep cloning creates a new object with all nested structures cloned, preventing mutation bugs and ensuring data isolation.

Q2. Compare structuredClone, JSON.parse(JSON.stringify(obj)), and lodash.cloneDeep in terms of features and limitations.
Expected answer signal

  • structuredClone: Handles most types, supports circular refs, but not functions/DOM nodes.
  • JSON: Fast, but loses functions, Dates, Maps, Sets, RegExps, and fails on circular refs.
  • lodash.cloneDeep: Handles most types, supports circular refs, but not functions/DOM nodes, slower than native.

Q3. What happens if you try to deep clone an object with a Date, a function, and a circular reference using each method?
Expected answer signal

  • structuredClone: Clones Date and circular refs, throws on functions.
  • JSON: Loses Date (becomes string), omits function, throws on circular refs.
  • lodash.cloneDeep: Clones Date and circular refs, skips function.

Q5. When should you prefer each method for deep cloning?
Expected answer signal

  • structuredClone: For complex/circular data in modern environments.
  • JSON: For simple, JSON-safe data.
  • lodash.cloneDeep: For legacy support or when structuredClone is unavailable.
