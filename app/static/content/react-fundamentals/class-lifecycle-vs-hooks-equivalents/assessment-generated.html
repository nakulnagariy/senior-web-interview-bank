React Class Lifecycle vs Hooks Equivalents Assessment

1. What is the hooks equivalent of componentDidMount?
Answer: useEffect(() => { ... }, []) runs once after the component mounts, just like componentDidMount.
2. How do you replicate componentWillUnmount with hooks?
Answer: Return a cleanup function from useEffect: useEffect(() => { return () => { ... } }, []).
3. How can you mimic componentDidUpdate with hooks?
Answer: Use useEffect(() => { ... }, [deps]). The effect runs after every update where dependencies change.
4. What hooks or patterns replace shouldComponentUpdate?
Answer: React.memo for components, useMemo and useCallback for values and functions, to prevent unnecessary re-renders.
