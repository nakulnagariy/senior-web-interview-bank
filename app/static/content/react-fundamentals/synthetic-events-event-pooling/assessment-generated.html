React Synthetic Events & Event Pooling Assessment

1. What is a SyntheticEvent in React?
Answer: A cross-browser wrapper around native events, providing a consistent API for event handling in React.
2. What is event pooling and why did React use it?
Answer: Event pooling is the reuse of SyntheticEvent objects for performance. React cleared and reused event objects to reduce memory usage.
3. What problem can event pooling cause in asynchronous code?
Answer: If you access event properties asynchronously (e.g., in a setTimeout), they may be null or undefined because the event object has been cleared and reused.
4. How do you prevent event pooling issues in React <17?
Answer: Call event.persist() inside your event handler to remove the event from the pool and keep its properties available asynchronously.
5. Coding: Show an example where event pooling causes a bug, and how to fix it.
Answer: 
{`// Buggy (React <17)
function MyButton() {
  function handleClick(e) {
    setTimeout(() => {
      alert(e.type); // e.type may be null
    }, 100);
  }
  return ;
}

// Fixed
function MyButton() {
  function handleClick(e) {
    e.persist();
    setTimeout(() => {
      alert(e.type); // e.type is preserved
    }, 100);
  }
  return ;
}
`}
