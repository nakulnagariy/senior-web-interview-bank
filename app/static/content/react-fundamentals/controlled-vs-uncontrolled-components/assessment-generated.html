React Fiber: Controlled vs Uncontrolled Components Assessment

1. What is a controlled component in React?
Answer: A controlled component is one where form data is managed by React state, and the input value is set via a prop and updated with an onChange handler.
2. What is an uncontrolled component in React?
Answer: An uncontrolled component stores its state internally in the DOM, and React accesses the value using refs instead of state.
3. How does React Fiber affect controlled and uncontrolled components?
Answer: Fiber's incremental rendering and scheduling make controlled components more predictable, as state updates are batched and managed by React. Uncontrolled components may not benefit from Fiber's scheduling since their state is outside React.
4. What are the advantages and disadvantages of controlled vs uncontrolled components?
Answer:
  • Controlled: Easier validation, formatting, and synchronization; more React overhead.
  • Uncontrolled: Less React overhead, simpler for basic forms; harder to validate and synchronize.
5. Coding: Write a controlled and an uncontrolled input component in React.
Answer: 
// Controlled
function ControlledInput() {
  const [value, setValue] = React.useState('');
  return <input value={value} onChange={e => setValue(e.target.value)} />;
}

// Uncontrolled
function UncontrolledInput() {
  const inputRef = React.useRef();
  return <input ref={inputRef} />;
}
