React Keys Assessment

1. Why are keys important in React lists?
Answer: Keys help React identify which items have changed, been added, or removed, enabling efficient updates and preserving component state.
2. What is a bad key pattern, and why is it problematic?
Answer: Using array indexes as keys is a bad pattern, especially if the list can change order or have items inserted/removed. It can cause loss of state and unnecessary re-renders.
