React Fiber & Incremental Rendering Assessment

1. What was the main limitation of React's stack-based reconciler before Fiber?
Answer: It was synchronous and blocked the main thread, causing UI freezes during large updates.
2. How does React Fiber enable incremental rendering?
Answer: Fiber splits rendering work into units, allowing React to pause, resume, and yield control to the browser between units, making rendering incremental and interruptible.
3. What are the benefits of incremental rendering in React Fiber?
Answer: Smoother UI, improved responsiveness, ability to prioritize updates, and avoidance of main thread blocking.
4. How does Fiber support prioritization and concurrency in rendering?
Answer: Fiber assigns priorities to updates and can work on multiple tasks concurrently, pausing lower-priority work for higher-priority tasks.
