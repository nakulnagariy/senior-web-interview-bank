React Strict Mode Assessment

1. What is the purpose of React Strict Mode?
Answer: To highlight potential problems, unsafe patterns, and side effects in React applications during development.
2. What happens to component functions and effects under Strict Mode in development?
Answer: They are intentionally invoked twice to help catch side effects and ensure code is resilient and idempotent.
3. Does React Strict Mode affect production builds?
Answer: No, Strict Mode only affects development builds. Production builds do not have double invocations or extra checks.
4. What kind of issues can Strict Mode help you catch?
Answer: Unsafe lifecycle methods, unexpected side effects, usage of deprecated APIs, and non-idempotent code.
