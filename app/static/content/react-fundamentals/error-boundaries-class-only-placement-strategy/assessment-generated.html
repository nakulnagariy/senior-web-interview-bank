React Error Boundaries Assessment

1. Why are error boundaries class-only in React?
Answer: Error boundaries rely on class lifecycle methods (componentDidCatch and getDerivedStateFromError), which are not available in function components or hooks.
2. What is the purpose of componentDidCatch and getDerivedStateFromError in error boundaries?
Answer: getDerivedStateFromError updates state to show a fallback UI, while componentDidCatch logs the error or sends it to monitoring.
3. Why does placement strategy matter for error boundaries?
Answer: Error boundaries only catch errors in their child tree. Placement determines which parts of the UI are isolated and how much is replaced by the fallback.

5. What are the limitations of error boundaries?
Answer: They cannot catch errors in event handlers, async code, or themselves. Only errors in rendering, lifecycle, and constructors of child components are caught.
