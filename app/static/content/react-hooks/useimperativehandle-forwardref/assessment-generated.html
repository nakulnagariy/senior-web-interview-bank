useImperativeHandle & forwardRef Assessment

1. What problem does forwardRef solve in React?
Answer: It allows parent components to pass refs through to child components, enabling access to a child’s DOM node or imperative methods.
2. How does useImperativeHandle enhance the use of forwardRef?
Answer: It lets you customize and control what is exposed to the parent via the ref, rather than exposing the entire child component or DOM node.
3. Give a use case where useImperativeHandle is preferable to just passing a ref to a DOM node.
Answer: When you want to expose only specific methods (e.g., focus, clear) or state to the parent, hiding internal details and encapsulating logic.
4. Coding: Write a custom input component that exposes focus and clear methods to the parent using forwardRef and useImperativeHandle.
Answer: 
{`const FancyInput = React.forwardRef((props, ref) => {
  const inputRef = useRef();
  useImperativeHandle(ref, () => ({
    focus: () => inputRef.current.focus(),
    clear: () => (inputRef.current.value = '')
  }));
  return ;
});`}
5. What are the risks or anti-patterns of overusing useImperativeHandle?
Answer: Overusing it can break encapsulation, make components harder to reason about, and lead to tightly coupled parent-child relationships. Prefer declarative patterns when possible.
