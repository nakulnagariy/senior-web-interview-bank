Custom Hooks: Design Patterns & Rules of Hooks Assessment

1. What is a custom hook in React?
Answer: A reusable function that encapsulates logic using React hooks, enabling code reuse and abstraction.
2. What are the two main rules of hooks?
Answer: Only call hooks at the top level (not inside loops, conditions, or nested functions), and only call hooks from React function components or other custom hooks.
3. What design patterns are commonly used in custom hooks?
Answer:
  • Encapsulation of complex logic
  • Composition of multiple hooks
  • Parameterization for customization
  • Returning state and utility functions
4. Coding: Write a custom hook for fetching data and explain its design pattern.
Answer: 
{`function useFetch(url) {
  const [data, setData] = useState(null);
  useEffect(() => {
    fetch(url).then(res => res.json()).then(setData);
  }, [url]);
  return data;
}
// Design: Encapsulates fetch logic, parameterized by URL, returns state.`}
5. Why must custom hooks start with "use"?
Answer: The "use" prefix allows React and linting tools to identify hooks and enforce rules automatically.
