useRef: DOM Refs vs Mutable Values Assessment

1. What is the primary use of useRef in React?
Answer: Referencing DOM nodes or persisting mutable values across renders without causing re-renders.
2. How does updating a useRef value differ from updating state?
Answer: Updating ref.current does not trigger a re-render, while updating state does.
3. Give two use cases for useRef: one for DOM access, one for a mutable value.
Answer:
  • DOM access: Focusing an input element.
  • Mutable value: Storing a timer ID or previous value between renders.
4. Coding: Show an example of using useRef for both a DOM ref and a mutable value in the same component.
Answer: 
{`function Example() {
  const inputRef = useRef(); // DOM ref
  const countRef = useRef(0); // Mutable value

  useEffect(() => {
    inputRef.current.focus();
    countRef.current += 1;
  });

  return ;
}`}
5. Why would you use useRef instead of state for a value?
Answer: When you want to persist a value across renders but don't want to trigger a re-render when it changes.
