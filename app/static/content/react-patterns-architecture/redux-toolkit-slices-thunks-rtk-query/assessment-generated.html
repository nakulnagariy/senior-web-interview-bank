Q1. What is a slice in Redux Toolkit and how does it improve Redux code structure?
Expected answer signal

Explains that a slice groups state, reducers, and actions for a feature, reducing boilerplate and improving modularity.

Q2. How does createAsyncThunk simplify async logic compared to manual thunks?
Expected answer signal

Describes that createAsyncThunk generates pending/fulfilled/rejected actions, handles promise lifecycles, and integrates with slices via extraReducers.

Q3. What is RTK Query and how does it differ from traditional Redux data fetching?
Expected answer signal

Explains that RTK Query is a data fetching and caching tool that generates endpoints and hooks, manages cache, and reduces the need for manual thunks/selectors.

Q5. What are the trade-offs of using RTK Query compared to manual thunks and selectors?
Expected answer signal

Mentions that RTK Query reduces boilerplate and manages cache, but adds abstraction and may not fit all custom logic or non-CRUD workflows.
