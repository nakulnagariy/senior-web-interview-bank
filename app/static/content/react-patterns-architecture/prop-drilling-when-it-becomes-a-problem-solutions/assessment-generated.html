Prop Drilling Assessment

1. What is prop drilling in React?
Answer: Passing data or functions from a parent to deeply nested children through props, even if intermediate components don’t use them.
2. When does prop drilling become a problem?
Answer: When data must be passed through many layers, leading to tightly coupled components, harder maintenance, and more difficult refactoring.
3. Name two solutions to prop drilling and explain when you would use each.
Answer:
  • Context API: For sharing data across many components without passing props manually.
  • State management libraries: For complex or global state that needs to be accessed or updated from many places.

5. What are the trade-offs of using Context or state management libraries to solve prop drilling?
Answer: Context and state libraries add complexity and can cause unnecessary re-renders if not used carefully, but they greatly improve maintainability and scalability for large apps.
