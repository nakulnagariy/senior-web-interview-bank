Q2. How does the order of chaining map, filter, and reduce affect the final result? Give an example.
Expected answer signal

Order matters: filtering before mapping can yield different results than mapping before filtering. Example: [1,2,3].map(x => x*2).filter(x => x>3) vs [1,2,3].filter(x => x>1).map(x => x*2).

Q5. What are some pitfalls or performance considerations when chaining these methods on large arrays?
Expected answer signal

Each method creates a new array, which can be inefficient for large data sets. Consider using for-loops or libraries like lodash for performance-critical code.
