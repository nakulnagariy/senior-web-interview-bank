# Interview bank

Every question asked in an `interview-coach` session lives here, with what I answered, the gaps, and the complete answer. Read this folder before the interview. Start with [INDEX.md](INDEX.md): it lists every file and how many gaps are still open.

## Layout

```
interview-bank/
  INDEX.md                 generated by `npm run bank:index` (in app/)
  <category>/<topic>.md    one file per topic, many questions per file
```

## Entry template

Every question uses exactly this shape (the index script reads the `Status` line):

```md
### Q: <the question exactly as asked>

- **Asked:** YYYY-MM-DD · **Verdict:** Correct | Partial | Wrong · **Status:** open | closed

**My answer (as given)**
<faithful, condensed record, mistakes included>

**Covered well**
- ...

**Gaps (note)**
- <missing / wrong / vague point and why an interviewer cares>

**Complete answer**
<the full interview-ready answer that closes every gap: spoken-style, trade-offs, alternatives, production angle, code if relevant. Mark unverified claims "(verify)".>

**Likely follow-ups**
- <follow-up> — <one-line answer>

**History**
- YYYY-MM-DD: first asked, Partial
```

Rules: never duplicate a question (update its History and Status instead); never delete old entries; `Status: closed` only after it was answered correctly on a re-ask.

## In the app

The web app has an **🧠 Interview Bank** tab that reads these files (bundled at build time, so it works offline on your phone). It lists questions by category, searches across them, and has a **Revise** mode: question first, reveal the answer, then mark "Got it" or "Still shaky". Those marks are saved on the device only (not written back to the Markdown `Status`). After a coaching session, rebuild and redeploy the app to see new entries on your phone.

## Before the interview

1. Open [INDEX.md](INDEX.md) and start with the files that have open gaps.
2. Read only **Gaps** and **Complete answer** for each open entry, then say the answer out loud.
3. Or run `/revise <category>` in Claude Code to be quizzed on the open entries first.
